# GST Revenue Forecasting – Business Analytics Project

## 📊 Project Overview

This project applies business analytics and quantitative forecasting techniques to estimate India's GST revenue for FY 2026–27.

The analysis combines taxation principles with statistical forecasting to identify historical GST revenue trends, define key revenue drivers, develop a regression-based forecasting model, and evaluate alternative revenue scenarios.

## 🎯 Objectives

* Analyze historical GST revenue trends
* Identify key factors influencing GST collections
* Apply trend analysis and linear regression
* Forecast GST revenue for FY 2026–27
* Develop conservative, base and optimistic scenarios
* Translate quantitative results into business recommendations

## 📚 Data Sources

The analysis uses publicly available Indian government data, primarily from:

* Goods and Services Tax Council
* Press Information Bureau (PIB)
* Ministry of Finance, Government of India

## 🧮 Methodology

The project follows these steps:

1. Collect historical GST revenue data
2. Clean and structure the dataset
3. Calculate year-over-year revenue growth
4. Analyze the historical trend
5. Develop a linear regression model
6. Evaluate model fit using MAE and MAPE
7. Generate the FY 2026–27 forecast
8. Develop scenario-based forecasts
9. Interpret the results from a taxation and business perspective

## 📈 Forecast Result

The base-case linear trend model produces an estimated FY 2026–27 GST revenue of approximately:

**₹25.97 lakh crore**

Scenario analysis:

| Scenario     |          Forecast |
| ------------ | ----------------: |
| Conservative | ₹24.41 lakh crore |
| Base Case    | ₹25.97 lakh crore |
| Optimistic   | ₹27.53 lakh crore |

These figures are analytical estimates generated by the project model and should not be interpreted as official government forecasts.

## 🔍 Key Insights

* India's GST revenue has shown a substantial long-term upward trend.
* Revenue growth has not been uniform across financial years.
* GST collections are influenced by consumption, imports, taxpayer formalisation, compliance, tax rates and refunds.
* A simple time-trend model provides a transparent baseline but does not establish causal relationships.
* A production-grade forecasting system should incorporate monthly data and additional macroeconomic and GST-specific variables.

## ⚠️ Limitations

The base model uses a relatively small annual dataset. Therefore, the forecast should be treated as a business analytics exercise rather than an official revenue projection.

Future improvements could include:

* Monthly GST data
* GDP and nominal consumption
* Import data
* E-way bill activity
* Taxpayer registrations
* Refund data
* GST rate changes
* SARIMA or other time-series models
* Multivariate regression
* Out-of-sample validation
